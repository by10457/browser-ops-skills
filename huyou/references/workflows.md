# 页面行为与匹配约束

## 上下文与帖子

账号昵称来自页面头部头像，操作计划同时保存头像标识。昵称和头像不是服务端 UID。活动圈子按钮、侧栏圈子名称及圈子主标签必须与绑定一致。

帖子 ID 来自列表容器的 data-feed-id，保持字符串。独立置顶横幅和侧栏推荐不作为帖子。snapshotKey 是可能随文本和日期变化的摘要，不代替帖子 ID。按昵称去重只是近似用户去重。

查询要求新发排序，默认排除插入热门。queryPosts 支持有上限的加载和日期解析；preview 仅取已加载快照。缺少 ID、时间不明或正文截断时如实报告，不猜测永久链接或用户身份。

## 动作与证据

- 通过帖子评论按钮打开详情，核对正文、作者和圈子。
- 回复目标按昵称、头像和完整正文唯一匹配，验证回复位于指定父评论之下，不以序号长期定位。
- 帖子点赞通过快捷菜单中标为“点赞”的表情完成，匹配标签及表情标识，不依赖菜单顺序。点击即提交；prepare/rehearse 不点击表情。
- 评论点赞要求可识别状态，不根据计数猜测是否已赞。
- 发布核对选中圈子、正文和内容声明，拒绝不支持的附件或分区参数。

评论/回复以新增同账号同文条目核对；帖子点赞以新增同账号点赞表情核对；评论点赞以明确状态或图标与计数共同变化核对；发布以新增同账号同文帖子 ID 核对。缺少肯定证据保持 uncertain，不凭公共计数增加判成功。

## 页面恢复

工具只清理仍与自身输入一致的草稿，不覆盖用户编辑。已有草稿阻止破坏性导航，提交不确定时保留现场。操作会激活标签页；发布路由未渲染表单时，仅在没有编辑器和草稿的情况下尝试一次恢复刷新。清理警告要求调用方检查页面。

选择器与表情资源标识由脚本维护。调用方使用公开接口；结构变化导致匹配失败时停止，由维护者修订适配器。
